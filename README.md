# Financial Feasibility Analysis of a Multi-Purpose Sports Club in Iran, in 2026

## Project Overview

This project evaluates the financial feasibility of establishing a multi-purpose sports club. The analysis uses financial modeling and investment appraisal techniques to assess the project's profitability, investment requirements, and long-term financial viability.

The financial model was developed using Microsoft Excel and incorporates projected cash flows, financing assumptions, and key investment performance indicators.

## Objectives

- Evaluate the financial feasibility of the proposed investment.
- Estimate the initial investment and projected cash flows.
- Assess investment profitability using standard capital budgeting techniques.
- Examine the relationship between project returns and the required rate of return.
- Support investment decision-making through quantitative financial analysis.

## Tools and Methods

- **Microsoft Excel:** Financial modeling and cash flow analysis
- **Net Present Value (NPV):** Evaluation of the present value of projected cash flows
- **Internal Rate of Return (IRR):** Assessment of the project's implied rate of return
- **Payback Period:** Estimation of the time required to recover the initial investment
- **Sensitivity Analysis:** Evaluation of how changes in key assumptions affect project feasibility

## Key Results

The analysis produced the following results under the project's assumptions:

- **Initial Investment:** IRR 15,523,000,000 Toman
- **Net Present Value (NPV):** 3,925,357,475.48 Toman
- **Internal Rate of Return (IRR):** Approximately 45%
- **Payback Period:** Approximately 4.96 years
- **Minimum Attractive Rate of Return (MARR):** 37%

Based on the modeled assumptions, the project yielded a positive NPV and an IRR above the required rate of return, indicating potential financial feasibility.

These findings depend on the assumptions and projections used in the model and should not be interpreted as a guarantee of actual investment performance.
